# Vara Prasad — Developer Portfolio

A responsive personal developer portfolio built with semantic HTML and CSS. It demonstrates Flexbox, CSS Grid, responsive media queries, a simple colour/type system, and real project links.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## GitHub Pages deployment

1. Create a public GitHub repository named `devfolio`.
2. Add `index.html`, `style.css`, and `README.md` to the repository root.
3. Push the project to the `main` branch.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Open the published URL and verify it in an incognito/private window.
