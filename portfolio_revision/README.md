# Vara Prasad — Developer Portfolio

A responsive personal developer portfolio built with semantic HTML and CSS. It demonstrates Flexbox, CSS Grid, responsive media queries, and accessible color contrast.

## Run locally

1. Clone the repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## GitHub Pages deployment

1. Confirm the `devfolio` repository exists and is public.
2. Add `index.html`, `style.css`, and `README.md` to the repository root.
3. Push the project to the `main` branch.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Open the published URL and verify it in a private window.
